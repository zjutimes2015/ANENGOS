## 路径 A：域名已备案（推荐，最终形态）

```
用户 → https://anengos.cn → Nginx :443 → 容器 :8080
                          → :80 重定向到 :443
```

1. DNS：A 记录 `anengos.cn` → `81.71.13.143`（DNSPod/阿里云控制台，TTL 600）
2. 服务器装 Nginx + 申请证书（certbot / 腾讯云免费 SSL）
3. Nginx 反代：`proxy_pass http://127.0.0.1:8080`，WebSocket 支持（管理台/任务流需要 `Upgrade` 头）
4. 安全组放行 80/443
5. 验证：`curl -I https://anengos.cn/health` 返回 200

## 路径 B：域名未备案（过渡方案）

1. DNS：A 记录 `anengos.cn` → `81.71.13.143`
2. 访问 `http://anengos.cn:8080`（备案完成后切路径 A）
3. 或先用境外节点 / CDN 反代（不推荐，国内合规风险）

> 中国法规：解析到境内服务器的 HTTP/HTTPS（80/443）必须 ICP 备案；未备案会被接入商拦截。8080 等非常规端口不受此限，但客户体验差，仅作过渡。
