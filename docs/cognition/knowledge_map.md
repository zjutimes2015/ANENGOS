1. **真正"已知"的只有 4 个核心件**：paper_trader / retro_loop / error_log / quant_ersibang（二四棒）。

2. **三个选股器（multifactor/all_a/screener）全是"未验证代码"**（2.6 分）：
   - 只有每日截面输出，**从未做过历史回测 / 样本外验证 / 过拟合判定**
   - 因子阈值（RSI<45、总分≥3、MA20 缓冲）无来源，IMP-003 正待人工复核
   - 但它们**已经在往 paper_trader 喂票买入**（10 只普通持仓来源）——这就是"AI 给的空气"
   - **行动：这三个必须先过晋升门（回测+虚拟盘）才能继续影响实盘决策，或降级为"仅观察"**

3. **quant_backtest 的过拟合门尚未真正验证自有策略**：
   - 9 种内置策略走 tradingview-mcp（通用策略，mock/真实混合）
   - **二四棒引擎（quant_ersibang）是独立实现，从未跑过 walk-forward**
   - 二四棒单票回测（600938）**跑输买入持有 -118%**，年化仅 +2.31% → 边界风险未量化，必须补过拟合门

4. **二四棒回测的已知硬伤（来自真实报告）**：
   - 2022-07~2026-10 区间：总收益 +9.39% vs 买入持有 +127.80%（严重跑输）
   - 优点：盈亏比 2.43、最大连亏仅 2 笔、回撤 1.91% —— 结构健康（截断亏损放大盈利）
   - 结论：二四棒适合作为"突破趋势票"的入场过滤器（配合趋势池），**不适合单独满仓跑单票**；
