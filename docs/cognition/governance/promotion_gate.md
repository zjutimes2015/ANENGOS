# ③ 晋升门规则（Promotion Gate）

> 新策略/新代码进入核心层的**唯一通道**。核心：**AI 写的代码默认在实验层**，
> 只有过完整晋升门 + 人确认，才成为"已知代码"。
> 对应方法论：**"你没认知的时候 AI 给你的就是空气"** —— 晋升门就是"认知验证器"。

## 层级定义

| 层级 | 含义 | 能做什么 | 禁止 |
|---|---|---|---|
| **实验层**（lab） | 新想法/未验证代码 | 回测、观察清单、研究 | ❌ 进入实盘/虚拟盘买入决策 |
| **核心层-虚拟盘验证中** | 已过回测门，虚拟盘跟踪中 | 虚拟盘自动买入跟踪 | ❌ 实盘下单 |
| **核心层-已验收** | 虚拟盘达标 + 人确认 | 可纳入实盘决策建议 | ❌ 自动实盘（决策仍由人） |

## 晋升门：四道闸（全过才升级）

### 闸1：回测质量门（Walk-Forward 过拟合判定）
- 引擎：quant_ersibang 或 quant_backtest（tradingview-mcp）
- **必须做样本内外切分**：前 80% 数据定参（in-sample）→ 后 20% 样本外验证（out-of-sample）
- 判定标准：
  - **ROBUST**：样本外仍盈利且回撤可控 → ✅ 通过
  - **MODERATE**：样本外衰减但不亏 → 观察，加过滤条件重测
  - **WEAK / OVERFITTED**：样本外亏损 / 样本内外差异巨大 → ❌ 淘汰，沉淀教训
- 数据要求：≥ 500 根日线（约 2 年），A股需前复权

### 闸2：基准对照（超额验证）
- 必须对比**买入持有基准**（同期同标的）和**指数基准**（沪深300/中证500）
- 通过线：样本外年化超额 > 0，且最大回撤 < 基准
- 反例教训：二四棒 600938 回测跑输买入持有 −118% → 不能作为独立 alpha（已在认知卡标注）

### 闸3：虚拟盘验证（Paper Trading）
- 进入"核心层-虚拟盘验证中"后，paper_trader 按策略分流自动跟踪
- 通过线：**连续 ≥ 4 周**跟踪，周复盘核对：
  - 卖出行为符合规则（止盈/止损/减仓真实触发）
  - 无数据 bug（error_log 无 open 级系统数据层日志）
  - 累计收益 ≥ 对照基准（同期的沪深300）或至少不显著跑输

### 闸4：人确认（Humans at the Edge）
- **最终拍板永远是你**：认知卡状态由你确认后变更，参数采纳由你决定
- 豆包/agent 只提交"晋级/降级建议 + 证据链"，不代替你改状态

## 操作流程

```
新想法/新策略
  └→ 实验层（写进认知卡，状态=实验层）
      └→ 闸1 walk-forward 回测（quant_backtest）
          ├─ WEAK/OVERFITTED → 淘汰（教训进 error_log/retro_loop）
          └─ ROBUST/MODERATE → 闸2 基准对照
              ├─ 超额 ≤ 0 → 降级观察 / 淘汰
              └─ 超额 > 0 → 闸3 虚拟盘（状态=核心层-虚拟盘验证中）
                  ├─ ≥4周未达标 → 降回实验层
                  └─ 达标 → 闸4 你确认 → 状态=核心层-已验收 ✅
```
