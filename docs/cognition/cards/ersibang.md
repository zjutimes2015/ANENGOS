## 1. 人话逻辑（这段是"为什么"，改代码前先读）

二四棒是**突破左侧峰值的趋势入场 + 移动止损的截断亏损系统**，不是预测系统：

1. **峰级线（左3右3）**：一根 K 线的最高价比左3根和右3根都高 → 确认一个"峰"（钉在 High）；
   最低价比左3根和右3根都低 → 确认一个"级"（钉在 Low）。严格的流式确认，无未来函数。
2. **趋势过滤**：新确认的级一截比一截矮（级下移段）→ 禁做多；级重新上移才恢复。
3. **入场**：价格突破最近已确认左峰的 High → 挂单成交（成交价 = 左峰价）。同一座左峰只敲一次门。
4. **初始止损** = 最近已确认左级的 Low（左级地板）。
5. **移动止损（只上移不放宽）**：仅当今日 High > 昨日 High 才更新为近4根最低；止损只升不降。
6. **离场**：当日 Low < 有效止损 → 按止损价出场。无主动止盈（全部靠移动止损让利润奔跑）。
7. **仓位**：风险定额 1%/笔 = 本金 × 1% ÷ (左峰价 − 左级价) → 反推股数（A股 100 股/手）。

**核心信念**：让亏损被严格截断（单笔 ≤ 2~7%），让盈利奔跑（移动止损跟着走）；
单笔盈亏比 2.43 的结构意味着胜率 40% 也能盈利。

## 3. 真实回测（已验证 · 2026-10-18 运行）

**标的：600938 中国海油 | 数据：新浪前复权日线 | 区间：2022-07-26 ~ 2026-10-16 | 1023 根 | 本金 100 万**

| 指标 | 数值 | 解读 |
|---|---|---|
| 已平仓 | 26 笔 | 样本偏小，统计力有限 |
| 胜率 | 61.5%（16/26） | 高 |
| 总收益 | +9.39%（年化 +2.31%） | **低** |
| 最大回撤 | 1.91%（19,085 元） | 优秀 |
| 夏普 / 索提诺 | 0.58 / 0.33 | 平庸 |
| 卡玛 | 1.21 | 及格 |
| 盈亏比 | 2.43（均盈 +9,964 / 均亏 −6,549） | 健康 |
| 最大连亏 | 2 笔 | 优秀 |
| 平均持仓 | 14.1 天 | 中短波段 |
| **基准对比** | 买入持有 +127.80%（年化 30.25%） | **策略跑输 −118.41%** ⚠️ |
| 分年度 | 2023 +3.77% / 2024 +4.63% / 2025 +0.75% / 2026 +0.46% | 逐年为正但都很低 |

**诚实结论**：二四棒在单票（600938）上**不是 alpha 来源**——它把回撤压得很小、结构很健康，
但收益远低于买入持有。它的价值是**作为趋势票的入场纪律**（截断亏损、不追高、只做突破回踩），
必须配合趋势选股池（quant_all_a Top30）使用，**不能单独满仓跑单票**。
