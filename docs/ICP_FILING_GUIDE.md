# siyu-ai.com ICP 备案办理清单 + 实名认证指引

> 适用：腾讯云轻量应用服务器（广州 81.71.13.143）+ siyu-ai.com
> 依据：腾讯云官方备案文档（2026-09 更新）｜ 预计耗时：7~20 个工作日

---

## 1. 备案是什么、为什么必须办

把域名和服务器绑定后，网站对外提供服务的 IP/域名必须向工信部登记（《互联网信息服务管理办法》）。未备案的域名解析到**中国大陆服务器**的 80/443 端口会被接入商拦截——所以目前 ANENGOS 走 `http://siyu-ai.com:8080` 过渡，备案通过后才能启用 `https://siyu-ai.com`。

## 2. 前置条件自查（不满足会卡在第一步）

- [ ] **服务器**：腾讯云轻量应用服务器（Lighthouse）需为**中国内地地域 + 包年包月**计费，购买时长 ≥ **90 天（3 个月，含续费）**，且备案期间剩余有效期 ≥ **30 天**
  - 查法：腾讯云控制台 → 轻量应用服务器 → 看实例的计费模式与到期时间
  - ⚠️ 如果你的实例是"按量计费"或剩余不足 30 天，先续费/转包年包月再备案
- [ ] **域名实名认证**：siyu-ai.com 需已完成实名认证，且认证完成满 **3 个自然日**（若域名不是在腾讯云注册的，需满 **3 个工作日**）
- [ ] **后缀合规**：.com 属于工信部批复后缀 ✅（此项已满足）
- [ ] **注册商在国内**：海外注册商的域名**不能备案**，须先转入腾讯云等国内服务商（见 §4 判断你的注册商）
- [ ] **三处信息一致**：域名实名认证信息 = 腾讯云账号实名 = 备案主体信息（姓名/证件号必须完全一致）
- [ ] **身份材料**：身份证原件照片（正反面，清晰无反光）

## 3. 材料清单（提前备好，一次过）

| 材料 | 说明 |
|---|---|
| 身份证正反面照片 | 本人手持/单独拍摄，jpg，≤2MB，四角完整无反光 |
| 域名 siyu-ai.com | 已实名认证（§4 指引） |
| 备案网站名称 | 如"思羽 AI 生产力操作系统"，≤30 字，不含"系统/平台"等敏感词 |
| 网站内容描述 | 一句话说明用途（如：面向企业提供 AI 多智能体任务治理与自动化服务） |
| 手机号 | 用于短信核验，需本人实名号码 |
| 核验单（如需要） | 腾讯云审核阶段会生成，下载打印签名拍照上传 |

## 4. 域名实名认证指引

**判断你的域名注册商**：腾讯云域名控制台（console.cloud.tencent.com/domain）→ siyu-ai.com →「域名信息」或联系记录。
- 若在**腾讯云/国内注册商**注册：直接在该控制台 → 域名列表 → siyu-ai.com → 「实名认证」→ 上传身份证 → 等待审核（通常 1 个工作日，认证完成后满 3 个自然日可备案）
- 若注册商在**海外**（如 Namecheap/GoDaddy）：**先转入腾讯云**（域名转入，约 5-7 天），转回后才能实名 + 备案；转入期间原 8080 访问不受影响

## 5. 腾讯云备案分步流程

1. **入口**：腾讯云控制台 → 搜索「备案」→ ICP 备案 → 「开始备案」（或用微信小程序「腾讯云备案」扫码办理，手机上即可操作）
2. **验证域名**：输入 `siyu-ai.com`，系统自动识别为"首次备案"
3. **填写主体信息**：个人备案填姓名/身份证/手机/地址；企业备案填营业执照/法人/经办人（按你主体类型选）
4. **填写网站信息**：网站名称 + 内容描述 + 选择云资源（选你的轻量服务器实例）
5. **上传材料**：身份证、核验单（如需）
6. **腾讯云审核**：1~2 个工作日，可能电话核验（保持手机畅通）
7. **短信核验**：审核通过后，工信部下发短信验证码 → 24 小时内登录备案系统输入核验码（**逾期作废需重来**）
8. **管局审核**：所在省通信管理局审核，一般 7~15 个工作日
9. **备案完成**：收到备案号（如"粤ICP备XXXXXXXX号"），同时可在备案系统下载备案证书

## 6. 时间线

| 阶段 | 耗时 |
|---|---|
| 域名实名认证（如未做） | 1 个工作日 + 3 自然日冷却 |
| 腾讯云初审 | 1~2 个工作日 |
| 短信核验 | 1 天（须 24h 内完成） |
| 管局审核 | 7~15 个工作日 |
| **合计** | **约 10~20 天** |

## 7. 常见驳回原因（一次过技巧）

- ❌ 域名未实名 / 实名未满冷却期 → 提前实名，等满 3 天
- ❌ 三处信息不一致（域名实名 ≠ 账号实名 ≠ 备案主体）→ 全部改成同一身份证信息
- ❌ 网站名称含"系统/平台/商城/网"等敏感词 → 用品牌名（如"思羽 AI 助手"）
- ❌ 身份证照片模糊/反光/切角 → 重拍，四角完整
- ❌ 短信核验超时 → 盯紧短信，当天处理
- ❌ 服务器不满足条件（按量计费/时长不足）→ 先转包年包月 ≥3 个月

## 8. 备案通过后（找我把 8080 切到 HTTPS）

备案拿到备案号后告诉我，我会完成：
1. 启用服务器已就位的 Nginx 反代（80 → 443 → 容器 8080）
2. 申请并配置腾讯云免费 SSL 证书
3. 安全组放行 80/443
4. 全站 HTTPS 验证 + 更新部署手册入口

> 相关：接入细节见 `docs/DOMAIN_SETUP.md`
