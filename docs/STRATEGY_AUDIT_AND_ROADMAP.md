# ANENGOS 策略诊断与三个月实盘改造路线图

> 生成日期：2026-11-22 ｜ 目标：三个月内（至 2027-02 下旬）产出一套**可上小资金实盘、力争正收益**的 A 股交易系统
> 范围：遍历沪深 A 股（不含北交所）；技术面 + 基本面结合；具备明确的进场位、出场位、止损位、移动止损位与挂单系统。
> 口径：本文所有绩效数字均来自服务器台账 `paper_positions.json` 与 workspace 回测/因子产物回读，非估算。

---

## 0. 一页纸结论

**工程骨架（取数、台账、cron、风控闸门、挂单表、飞书同步）已较完整；但策略本身尚未被验证出正期望 alpha。** 当前回测样本外多数失效或跑输基准，纸面盘胜率极低，因子层 alpha 薄到盖不住交易成本。继续堆 adapter、堆因子只会放大噪音。

正确路径不是再扩功能，而是：**先把一套策略在严格回测（含成本、PIT、样本外、年度分段）里验证过门，再小资金上实盘。**

- 纸面盘（约 1 个月）：胜率 **13.3%**，总盈亏 **-21,630**，两笔巨亏吞掉其余全部盈亏。
- 历史组合回测：总收益 **-49.5%**、Sharpe **-2.13**、回撤 **-52%**。
- 唯一在库 active 的因子族是**低波**，样本外超额仅 **0.32%~0.38%**，IR ≈ 0.096，不足以覆盖成本。
- 普通候选**固定买 100 股**、**买入时不设硬止损**、**无普通仓移动止损**、撮合未建模涨跌停/跳空/停牌。
- 本地行情库**无任何财务/估值/行业字段**，"基本面结合"在回测侧目前落不了地。

> 预期校准：三个月做到"可上小资金实盘"是可行目标；"长期稳定正收益"需要更长样本验证，**不承诺收益**。A 股 T+1、涨跌停、流动性是硬约束，回测必须如实建模。

### 1.4 根因（为什么费 token 但效果差）

1. **研究顺序反了**：先搭了大量 adapter 与工程入口，再回头找 alpha；而绝大多数因子在时序门就不显著，工程承载的是未验证的信号。
2. **因子冗余且单薄**：active 因子挤在同一低波族，没有跨风格（趋势/质量/价值/成长）的正交补充；静态截面 IC 被误当成可交易 alpha。
3. **交易规则不成体系**：进场无确认、定仓不按风险、止损无硬位、利润无跟随保护，导致"小亏不断、盈利靠运气、两笔失控巨亏"。
4. **回测口径不统一**：部分报告未计费用；样本内外切分粗糙；缺年度分段与极端情景压测；撮合理想化。
5. **数据底座缺财务层**：基本面无法 PIT 回放，"技术面+基本面"目前只是快照附加分。

## 2. 目标策略蓝图（波段主线，规则化可回测）

> 默认风格：**持仓 1~4 周波段**；短线连板（二四棒）仅作为独立高风险原型观察，不进主仓。该默认可在拍板项中调整。

### 2.1 股票池与排雷
- 范围：沪深 A 股，不含北交所；剔除 ST/*ST/退市预警、长期停牌、上市不足 N 日。
- 流动性门槛：近 20 日日均成交额、换手率达标，保证可进出、冲击成本可控。
- 基本面排雷：商誉/质押比例过高、连续亏损、审计意见异常、近期财报暴雷预警。

### 2.2 进场（双层过滤，给出进场价）
- **基本面层（PIT）**：盈利为正，ROE / 净利率 / 成长达到门槛，估值不过分贵，无重大排雷项。
- **技术面层**：价格在 MA20/MA60 之上；相对强度领先所属指数；量能确认（突破放量或回踩缩量）；距 250 日高点位置合理。
- **买点类型**：① 回踩 MA20/MA60 缩量企稳；② 放量突破左峰平台。进场以**限价挂单**给出价格区间，不追高。

### 2.3 定仓（风险定额）
- `股数 = min(风险预算/止损距离, 单票市值上限, 可用现金)`，百股取整，保底 100 股。
- 风险预算 = 权益 × 单笔风险比例（默认 1.0%~1.5%）。
- 组合层：单票市值上限、行业集中度上限、持仓只数上限；相关性过高的标的不重复加仓。

### 2.4 止损与移动止损
- **初始硬止损**：结构位（最近波段低点 / 左级 Low）或 ATR 倍数，取更近者；买入成交即落 `init_stop`，不依赖事后破均线。
- **盈亏平衡止损**：浮盈达到第一目标位后，止损上移至成本价。
- **移动止损**：之后用近 N 根最低 / 吊灯止损 / 均线 trailing，**只上移不下移**；触及 trailing 离场。

### 2.5 止盈与出场
- **分批止盈**：如 +1R 减 1/3、+2R 再减 1/3，剩余仓位跟随移动止损吃趋势。
- **结构目标位**：前高/测量目标到达可分批兑现。
- **时间止损**：持有 N 个交易日无进展（未达预期且走弱）离场。
- **基本面退出门**：持仓期内财报/公告触发排雷条件，离场。

### 2.6 挂单系统
- 买入：突破价 / 回踩价限价单，设有效期，未成交自动作废；撤单/改单留痕。
- 卖出：持仓期间挂出止损单、止盈单；触发按规则成交。
- 撮合模拟：一字涨停不成交、跳空按更差价格成交、停牌顺延、T+1 当日买入不可卖。

### 2.7 记录与归因
- 每笔交易结构化记录：进场理由、进场价、初始止损位、目标位、定仓依据、出场理由、出场价、持有天数、盈亏 R 倍数、数据来源。
- 周复盘可逐笔归因，区分"规则内亏损"与"规则外/数据 bug 亏损"。

## 4. 实盘前必须通过的硬门（量化验收清单）

### 4.1 回测门（闸1/闸2）
- [ ] Walk-forward 滚动样本外，**扣费后年化 > 0** 且跑赢对应指数基准。
- [ ] Sharpe 参考 > 0.5；最大回撤 ≤ 基准或 ≤ 预设上限。
- [ ] 期望值为正：胜率 × 平均盈利 > 平均亏损 × 败率。
- [ ] 年度分段稳健：无单一年份严重亏损；牛/熊/震荡分段均可解释。
- [ ] 极端情景压测：急跌/流动性枯竭/微盘崩盘情景下回撤可控。
- [ ] 成本敏感：滑点/佣金上调一档后仍不亏；信号不过度依赖窄止损被洗。

### 4.2 虚拟盘门（闸3）
- [ ] 连续 ≥4 周（建议 8 周）跟踪，无 open 级数据/系统 bug。
- [ ] 卖出均按既定规则触发，可逐笔归因。
- [ ] 累计收益不显著跑输基准；回撤在预设限内。

### 4.3 实盘门（闸4 人确认）
- [ ] 小资金试运行：实际滑点、成交率、涨跌停买不进比例与回测假设偏差可接受。
- [ ] 每笔下单有人在环确认；仓位/止损/撤单流程可手动执行。
- [ ] 达到约定跟踪期与回撤目标后，才讨论放大资金。

| 实盘资金 | 小资金试水（回测口径 100 万） | 10~50 万；按你指定金额 |
| 最大回撤 | 组合熔断 10%~15% 停买；单笔风险 1.0%~1.5% | 更保守 8% / 更宽松 15%+ |
| 财务数据源 | 先 baostock 免费历史财报 PIT 入库，Tushare 增强 | 直接接 Tushare（需 token/额度）；暂不接、先通技术面 |
| 止损参数 | 结构位 / ATR 倍数；trailing 只上移 | 固定百分比；其他 |

**需要你确认的关键问题：**
1. 主做哪种持仓周期？（波段 / 短线连板 / 中长线 / 回测择优）
2. 实盘起步资金规模与可接受最大回撤？
3. 基本面数据是否愿意接 PIT 财务库（部分源需 token/额度）？
4. 实盘前验收门是否按 §4 全部保留，还是有要放宽/加严的项？

## 6. 风险提示

- 本系统当前**没有已验证的正期望策略**；任何未过门信号都不应进入实盘或自动纸仓买入。
- A 股 T+1、涨跌停、停牌、流动性冲击会显著改变实盘结果，回测必须如实建模，不能用理想限价成交。
- 低波族现有 alpha 太薄，不能作为主仓唯一依据；需要跨风格因子补充与组合层面控制。
- 历史回测不代表未来；样本外达标只是上小资金实盘的前提，不是盈利承诺。
